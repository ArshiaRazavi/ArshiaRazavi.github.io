## Abstract

How does the brain encode a new memory or activity pattern without forgetting previously learned ones? Although current theories suggest that memories are encoded in patterns of synaptic weights, the mechanisms by which these patterns are stabilized over time are not well understood. Individual synapses and neurons are unreliable, and their weights and responses can change over time. Recent studies suggest that activity patterns could be stabilized via complex plasticity mechanisms within a framework coined as "self-healing codes". However, it is still unclear whether the same mechanisms could produce stable memories in spiking networks and whether these learning rules are biologically plausible. Here, we present a biologically inspired spiking neural network based on Izhikevich neurons with synaptic plasticity. Synaptic learning occurs via spike time dependent plasticity on excitatory connections while preserving Dale's rule. An individual memory is stored by sequentially activating a subset of cells over consecutive trials until a stable response is achieved. Multiple memories are then learned sequentially by following the same procedure. Memory recall was achieved by reactivation of the initial cell subset and identification of responsive cells, i.e., a cell assembly. Assemblies eventually faded, usually after having learned ten new memories. Signatures of previous memories, however, could still be observed within the synaptic connectivity matrix over longer time scales. Although cell assemblies faded, the spiking response to a memory recall event was substantially different from the response to an equivalent random activation, suggesting that a memory trace could still be decodable.
